# 产品愿景与范围

## 1. 愿景

《逃离考场》想讲的是：在高考高压下，中国学生从「被试卷与纪律困住的身体」里逃出来，去看见更广阔的中国与自我。

- **情感内核**：禁锢 → 恐惧与肾上腺素 → 挣脱 → 路上的自由与成长。
- **文化定位**：中国独有语境（高考、监考、校园空间、高铁/地铁/机场），用叙事张力而非猎奇或丑化。
- **玩法骨架**（目标态，非当前仓库实现）：
  1. 潜行逃出考场（不能被监考发现）；
  2. 逃出学校；
  3. 坐高铁 / 飞机 / 地铁 / 车等，去中国各地做旅行任务；
  4. 多人时每人不同考场，逃出后在约定地点汇合。
- **技术态度**：原型优先、占位美术可接受；地图结构可参考 OSM；资源倾向开源可商用；重计算任务必须先问用户。

一句话给制作决策用：**先做出「逃」的节奏与情绪，再铺「游中国」的宽度；宽度未到之前，不要用生存、枪战、开放世界清单填满范围。**

---

## 2. 核心体验环（目标设计）

理想单局 / 单章体验环：

```
压力开场（考场纪律、倒计时或巡视）
    → 观察监考与空隙（潜行解谜）
    → 逃出考场（第一声自由）
    → 穿越校园（仍有被抓风险）
    → 抵达交通节点（购票/检票可简化）
    → 旅行任务（观光、跑腿、叙事事件）
    → （联机）与同伴汇合 / 下一章
```

当前仓库已覆盖体验环的占位切片：开世界黄圈、考场潜行、学校逃离、综合交通枢纽购票检票、旅行地标打卡。联机汇合与 OSM 真地图仍未合入。

---

## 3. 范围内 / 范围外

### 3.1 当前范围内（应持续投资）

- 第三人称移动与简单载具（已有基线，可打磨）
- 任务点（黄圈）系统的扩展（更多目标类型、文案、简单分支）
- 考场潜行 / 学校逃离 / 交通枢纽 / 旅行黄圈（已合入 v0.2–v0.3，可继续打磨）
- 中文 UI / 中文叙事文案
- 占位几何 + 可商用低模资源替换
- 文档与可演示里程碑

### 3.2 明确非目标（现阶段不要做）

| 非目标 | 原因 |
| --- | --- |
| 做成《饥荒》式生存（饥饿、造基地、天数循环当主循环） | 冲淡「逃」与「出走」主线 |
| 枪战、警察追捕大而全、犯罪模拟清单一次性堆上 | 范围爆炸；与高考叙事主轴易冲突 |
| 一上来精美次世代全地图 | 阻塞可玩进度；先占位 |
| 未商量的大模型 / GPU 训练 / 重渲染流水线 | 成本高，需用户拍板（见 `06`） |
| 把 OSM 全中国导入当 v0.2 前置 | 过重；后期再做 |
| 在潜行未稳前强上完整联机 | 同步与关卡设计会互相拖垮 |

### 3.3 「以后可以做」但不占用当前 P0/P1

- 联机汇合、更丰富交通仿真、OSM 结构关卡、URP 视觉升级、更复杂的监考 AI、旅行章节内容量产。

## 4. 里程碑建议

下列版本号是**产品规划标签**，不是 Git tag 承诺。完成定义（DoD）写的是「玩家能感知什么」。

### v0.1 — 已完成切片（仓库 main 基线）

**状态：已有可玩原型（Built-in + 旧 Input）。**

DoD（验收）：

- WASD 第三人称走路；
- F 上下车；
- 开车到黄圈出现「任务完成」；
- 占位场景可生成 / 可打开。

对应事实见 `00-任务交接.md`。

### v0.2 — 考场潜行 + 逃出学校

**状态：已合入。**

DoD（已验收设计）：

- 独立考场场景：监考视野锥、蹲走、掩体、失败重试、逃出考场；
- 学校走廊 + 巡逻 + 校门「逃出学校」；
- 不破坏 v0.1 OpenWorld。

### v0.3 — 交通枢纽 + 旅行任务（本里程碑合并交付）

**状态：已合入（极简占位）。**

DoD：

- 学校成功后可进入综合交通枢纽（高铁窗口 / 地铁闸机 / 机场值机同厅占位）；
- 靠近窗口按 **E** → 中文面板选车次（如「G-自由01」）→ 获得车票；
- 闸机：有票通过并加载旅行区；无票中文提示；
- 旅行区至少 3 个中国地标主题黄圈，中文完成反馈；
- 不破坏 ExamHall / SchoolEscape / OpenWorld 既有验收路径。

### v0.4 — 旅行任务扩展（后续）

**状态：基础已在 v0.3；更多章节未做。**

建议后续 DoD：

- 更多城市 / 任务类型与叙事文案；
- 任务之间更丰富的连接（载具、过场等）。

### v0.5 — 联机

**状态：未实现。**

建议 DoD：

- 使用 **Netcode for GameObjects**（或用户另行指定的方案）做最小联机；
- 每名玩家从**不同考场实例 / 不同 spawn** 开始潜行；
- 逃出后抵达共享「汇合点」并看到其他玩家；
- 文档写清主机 / 客户端职责与已知限制。

### 后期 — OSM / 精美化 / 管线升级

- 参考 OSM 真实道路与 POI 结构搭建关卡（注意 ODbL，见 `04`、`05`）；
- 美术从 Kenney / Quaternius / Poly Haven 等可商用源替换占位；
- 评估 URP 迁移（单独里程碑，含全量材质验收）；
- 叙事章节加长、多结局等。

---

## 5. 范围变更规则

1. 任何把里程碑从「潜行」跳到「全国开放世界 + 联机 + OSM」的提案，必须拆回可演示小切片。
2. 新增系统前先问：是否服务「逃」或「出走后的任务」？若否，降为后期。
3. 技术迁移（URP、新 Input、Netcode）单独成里程碑，不与叙事关卡第一版绑死。
4. 重任务默认不做，见 `06-重任务方案.md`。

---

## 6. 成功标准（产品层）

对用户而言，短期成功不是「系统清单打满」，而是：

- 能稳定演示 v0.1–v0.3 串联（考场→学校→枢纽→旅行打卡）；
- 文档与仓库进度一致，其他代理可无对话上下文接手。
