# 故事线

> 本章是叙事与关卡设计参考。除开场「高考压力」气氛可在未来关卡中使用外，**考场逃脱、学校、旅行任务、联机汇合均未在仓库中实现**。文中任务点子均标注「仅设计未实现」。

---

## 1. 主线梗概

**时代与处境**：高考临近或正在进行。教室里是试卷、答题卡、耳语般的纪律，窗外是被围墙切开的夏天。

**第一幕 — 考场**  
主角意识到：留下不只是一场考试，而是被「分数即命运」的叙事钉死。选择在监考的缝隙里离开座位，潜行通过考场，推开那扇不该在此刻推开的门。

**第二幕 — 学校**  
逃出教室不等于自由。走廊摄像头（可用叙事灯光暗示）、值班老师、锁着的侧门、翻越或骗过门卫的简化玩法。直到脚踩到校门外的柏油路，第一幕的肺才真正张开。

**第三幕 — 出走中国**  
车站大屏、地铁换乘、机场广播。交通工具是「把身体从考点坐标里拔出来」的仪式。抵达不同城市后，完成一串并不宏大、但属于自己的旅行任务——看山、送信、赴约、把一张空白志愿表折成纸船……

**多线（可选联机）**  
每个人的考场编号不同，恐惧相似。逃出后在约定的站前广场 / 某座桥 / 某趟列车汇合，才第一次用「我们」说话。

## 2. 象征与主题

| 象征 | 用法建议 | 避免 |
| --- | --- | --- |
| 试卷 / 答题卡 | 视觉噪音、墙上标语、被风吹散的纸 | 把整个游戏做成无玩法的「厌学发泄」 |
| 监考视线 | 玩法化的视野锥；压力来自被看见 | 丑化教师个体；监考是制度压力的化身即可 |
| 围墙与校门 | 空间节奏的「最后闸门」 | 过度写实到侵权或可识别真实学校 |
| 车票 / 车次 | 自由的收据；UI 可用一张简易车票 | 复杂票务仿真 |
| 空白志愿表 | 可在后期任务中出现的道具隐喻 | 说教长篇 |

**主题词**：禁锢、被观看、试卷洗脑（制度话语重复）、逃离羞耻与逃离勇气并存、自由是一条路而不是一个点。

**语气**：严肃里带一点青春期的荒诞与幽默即可，避免网络戾气堆砌。

## 3. 建议关卡节拍

### 节拍 A — 考场（v0.2）

1. 坐下 / 起立的一小段无法操作或半操作（建立纪律感）。
2. 教程：蹲、掩体、看视野锥。
3. 两三次「空隙」移动，到达后门或窗（设计任选其一为主出口）。
4. 失败则回到座位或检查点，短重试循环。

### 节拍 B — 学校（v0.2）

1. 走廊：横向巡逻或定点注视。
2. 操场边缘或车棚：掩体更多，节奏稍快。
3. 校门：一次简单交互（等待门卫转身 / 跟在假装家长的 NPC 影子里——NPC 可为占位胶囊体）。
4. 出校：过场到交通或先回到 OpenWorld 占位亦可（实现时与用户定）。

### 节拍 C — 枢纽（v0.3）

1. 买票（按 E 打开简 UI）。
2. 检票闸机（触发器）。
3. 上车过场。

### 节拍 D — 旅行（v0.4）

黄圈或对话触发；完成条件明确；奖励以叙事解锁 + 简单收集为主。

## 4. 旅行任务点子（仅设计未实现）

以下 **3–5 个**点子供 v0.4 选用，**均未实现**：

1. **「把分数扔进海里」**（仅设计未实现）  
   抵达一座滨海城市占位场景，走到防波堤黄圈，交互后播放简短文案：主角把一张复印的成绩单折纸，抛进海里（可用粒子占位）。主题：放下被定义的自己。

2. **「替同学寄出的明信片」**（仅设计未实现）  
   在火车站附近找到邮筒（占位），提交道具「明信片」。文案来自未能一起逃走的同伴。主题：连接与亏欠。

3. **「晚到的演唱会」**（仅设计未实现）  
   开车 / 地铁到体育馆外黄圈，任务完成条件是「赶到」而非「看完」。主题：为非功利的事情奔走。

4. **「志愿表上的空白行」**（仅设计未实现）  
   在山顶或城市观景台，打开 UI 在志愿表上写下玩家输入的短词（需限制长度与过滤）。主题：自己填写命运的一行。

5. **「汇合前的一碗面」**（仅设计未实现）  
   单机可做成与店员占位对话；联机版可要求两名玩家先后进入同一面馆触发点。主题：平凡的自由。

## 5. 多人对白 / 汇合叙事建议（未实现）

- **开场**：每人只看到自己的考场编号与座位号；语音/字幕避免剧透他人进度。
- **逃出瞬间**：本地短句（「我出来了」），不要全局播报暴露仍在潜行的玩家位置（也避免变成骚扰）。
- **汇合点**：站前钟楼 / 广场雕像 / 某车次车厢门——用大黄色汇合区域继承现有任务圈 UX。
- **汇合成功对白示例**（可改）：
  - A：「你从几考场出来的？」
  - B：「不重要。重要的是票还在。」
  - 系统：「汇合完成。下一站：自由。」
- **失败友好**：有人仍在考场时，已逃出玩家可在汇合区等待（表情/小动作），不要惩罚式踢人。

## 6. 文案与内容审查注意

- 不攻击真实学校、真实教师、真实考生群体。
- 不提供现实中考试作弊、伪造证件的可操作指南；游戏内「逃」是虚构冒险。
- 涉及自杀、自伤的表达一律禁止；压力主题用逃离与出走消化。
- UI 与对白保持简体中文，方言梗谨慎、可加字幕说明。
