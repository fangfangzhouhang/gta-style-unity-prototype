## 2. 潜行（v0.2 · 已实现最小闭环）

### 2.1 目标体验

玩家靠观察监考视野、利用掩体与蹲走，从座位移动到出口；被发现则失败重试，而不是战斗杀敌。

### 2.2 已实现规则（v0.2）

- **视野锥**：`VisionConeDetector`——扇形距离/角度 + 射线遇 Collider 则算掩体遮挡；进入扇形且无遮挡 → **直接发现**。
- **蹲走**：`ThirdPersonController`，**LeftControl / C**；降低速度与碰撞体高度（蹲本身不提供隐身，需靠掩体挡射线）。
- **掩体**：课桌 / 柜子带 `CoverTag` + BoxCollider。
- **失败**：`StealthGameHUD` 显示「被发现了」→ 传送回检查点并重置视野状态。
- **成功**：`ExamExitTrigger` →「逃出考场」→ 可选自动 `LoadScene("SchoolEscape")`。

### 2.3 建议调参入口（便于策划改）

- 视野角度、距离、发现所需时间；
- 蹲走速度倍率；
- 检查点 Transform。

### 2.4 明确不做（v0.2）

- 复杂光照 thruster、声音传播模拟、多智能体群体战术——可后期再加。

## 3. 学校逃离（v0.2 · 已实现最小闭环）

- 结构：线性走廊占位（`SchoolEscapeBuilder`）。
- 威胁：2 名 `SimplePatrol` + 同一套 `VisionConeDetector`。
- 终点：`SchoolGateTrigger` → UI「逃出学校」（v0.2 终点；暂不进交通枢纽）。
- 与考场共享：蹲走输入、失败重试、`StealthGameHUD` 中文提示。

## 4. 载具与任务点（已有 · 可扩展）

### 4.1 已有

- 上车 / 下车：F；
- 驾驶至黄色区域完成任务。

### 4.2 扩展建议（未实现）

- 多种任务类型：到达 / 交互 / 护送占位 NPC / 限时到达；
- 任务数据用 ScriptableObject（`MissionDefinition`）描述标题、说明、目标点、完成事件；
- UI：任务追踪面板（左上简短中文）；
- 保持黄圈作为「主目标可读性」的第一语言，颜色盲友好时可再加图标。

## 5. 交通枢纽流程（建议 · v0.3 · 未实现）

极度简化即可，避免做成票务模拟器：

1. **购票**：靠近窗口按 E → 面板显示车次「G-自由 01」→ 确认获得 `Ticket` 布尔或道具。
2. **检票**：靠近闸机，有票则开门/淡出，无票则提示。
3. **乘车**：加载下一场景或启用旅行区。

地铁 / 机场可用同一状态机换皮（文案与模型不同）。

## 6. 联机（建议 · v0.5 · 未实现）

### 6.1 技术建议

- **Netcode for GameObjects**（NGO）作为默认讨论方案；最终以用户批准为准。
- 先做「同场景少量玩家 + 主机权威」，不要先做专用服务器。

### 6.2 玩法建议

- **不同考场 spawn**：每人自己的考场实例（或同场景分隔房间 + 隔离视野）；
- **潜行阶段**：尽量少同步他人位置给仍在潜行的玩家（防破坏体验）；或接受简单同步但禁用干扰技能；
- **汇合点**：逃出成功后启用共享世界层，黄圈汇合；
- **断线**：友好提示，允许重连回汇合区（细节实现时再定）。

### 6.3 非目标（联机第一版）

- 反作弊、匹配大厅美化、跨平台语音——均可更晚。

## 10. 验收口径（设计是否做对）

- 新系统是否能在 5 分钟内向用户讲清「怎么玩、怎么赢、怎么败」；
- 是否仍能一键回到 OpenWorld 演示 v0.1；
- 是否没有把未实现功能写进 README 已完成区。
