## 2. 潜行（v0.2 · 已实现最小闭环）

### 2.1 目标体验

玩家靠观察监考视野、利用掩体与蹲走，从座位移动到出口；被发现则失败重试，而不是战斗杀敌。

### 2.2 已实现规则（v0.2）

- **视野锥**：`VisionConeDetector`——扇形距离/角度 + 射线遇 Collider 则算掩体遮挡；进入扇形且无遮挡 → **直接发现**。
- **蹲走**：`ThirdPersonController`，**LeftControl / C**；降低速度与碰撞体高度（蹲本身不提供隐身，需靠掩体挡射线）。
- **掩体**：课桌 / 柜子带 `CoverTag` + BoxCollider。
- **失败**：`StealthGameHUD` 显示「被发现了」→ 传送回检查点并重置视野状态。
- **成功**：`ExamExitTrigger` →「逃出考场」→ 可选自动 `LoadScene("SchoolEscape")`。

### 2.3 建议调参入口（便于策划改）

- 视野角度、距离、发现所需时间；
- 蹲走速度倍率；
- 检查点 Transform。

### 2.4 明确不做（v0.2）

- 复杂光照 thruster、声音传播模拟、多智能体群体战术——可后期再加。

## 3. 学校逃离（v0.2 · 已实现最小闭环）

- 结构：线性走廊占位（`SchoolEscapeBuilder`）。
- 威胁：2 名 `SimplePatrol` + 同一套 `VisionConeDetector`。
- 终点：`SchoolGateTrigger` → UI「逃出学校」→ 可选自动 `LoadScene("TransitHub")`（v0.3）。
- 与考场共享：蹲走输入、失败重试、`StealthGameHUD` 中文提示。

## 5. 交通枢纽流程（v0.3 · 已实现极简）

避免做成票务模拟器；当前为**综合站同厅占位**：

1. **购票**：`TicketWindowInteract` 靠近按 **E** → `TransitGameHUD` 面板选「G-自由01」等 → `TicketInventory.Grant`。
2. **检票**：`TicketGateInteract` 触发器；有票 → `TransitFlowController` 成功横幅后 `LoadScene("TravelMissions")`；无票中文提示。
3. **机场值机**：同组件换皮（右侧柜台），亦可购票。
4. **限制**：无真实安检/排队/动画列车；车票为静态布尔；无 OSM。

脚本：`Assets/Scripts/Transit/`；菜单：**EscapeExam → 生成交通枢纽场景**。

## 5.1 旅行任务（v0.3 · 已实现最小集）

- 数据：`TravelMissionCatalog` 静态 3 条（西湖断桥 / 长城烽火台 / 黄山迎客松）。
- 黄圈：`TravelMissionPoint` + `TravelMissionController`；中文反馈 `TravelGameHUD`。

- **未做**：ScriptableObject 资产管线、载具连环任务。联机汇合见 §6 骨架。

## 6. 联机（v0.5 · 骨架已实现 · 非完整产品）

### 6.1 技术

- **Netcode for GameObjects** `com.unity.netcode.gameobjects` **1.12.0** + Unity Transport（本地 / 局域网）。
- Host 权威会话；`EscapeNetworkBootstrap` 中文 Host/Client UI；`NetworkPlayer` 用 NetworkVariable 同步位置朝向。
- 单机：无 NetworkManager 会话时走原流程（`OfflineFallback`）；Esc「联机大厅」为可选入口。
- **后期可选**：Unity Relay / Lobby（付费或额度限制）——本骨架**未**接入；Docs 仅占位说明。
- **明确不做（本版）**：Vivox/语音、匹配服、完善反作弊。

### 6.2 玩法（骨架）

- **不同考场 spawn**：`ExamRoomAssigner` 按 clientId 分配 2–4 间分隔考场；
- **潜行**：各房间本地老师 AI（未做权威反作弊）；
- **汇合点**：`MeetupZone` + `EscapeNetProgress.HasEscaped`；绿门逃出后传送；≥2 人到达显示「队友已汇合」。

### 6.3 脚本 / 场景

- `Assets/Scripts/Net/`：`EscapeNetworkBootstrap`、`ExamRoomAssigner`、`NetworkPlayer`/`NetworkPlayerSpawner`、`MeetupZone`、`EscapeNetProgress`、`OfflineFallback`…
- 场景：`NetLobby`、`NetExamHall`、`NetMeetup`；菜单 **EscapeExam → 生成联机大厅/联机考场骨架**。

### 6.4 非目标（仍适用）

- 反作弊、匹配大厅美化、跨平台语音、Relay 默认依赖——均可更晚。

## v0.4 系统补充（已实现占位）

### 老师 AI（`TeacherAgent`）

- 状态：巡逻（随机下一路点）→ 追赶（视野发现）→ 抓住（距离阈值）。
- 考场 / 学校 Flow 监听 `OnCaughtPlayer`：传送检查点 + 「被迫学习」锁定 → 恢复控制再逃。

### 进度与存档

- `GameProgress`（DontDestroyOnLoad）：阶段、资金、手机、留条、地图解锁、检查点。
- `SaveSystem`：`persistentDataPath/escape_exam_save.json` + PlayerPrefs 镜像。
- `PauseMenu`：Esc → 继续 / 保存 / 读取 / 退出到标题（HubTown）/ 退出游戏。

### 旅行门槛主线

```
ExamHall → SchoolEscape → HubTown
  → Home（留条，不被家长发现）
  → 买手机 + 黄圈赚钱
  → TransitHub（无手机不可见票价；票价扣款；需已留条）
  → TravelMissions
```

### 经济

- `Wallet` / 手机商店价 50；票价 G80 / D50 / C30；旅行打卡 +25；城镇黄圈 35–45。

### 地图

- 逃出学校后 `mapUnlocked`；HubTown 按 **M** 打开 `WorldMapUI`（景点 + 枢纽图标说明）。
