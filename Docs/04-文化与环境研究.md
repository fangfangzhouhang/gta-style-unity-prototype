# 文化与环境研究

> 研究笔记级参考，供关卡、文案、美术气氛使用。强调**叙事张力**，避免刻板印象与冒犯。不是社会学论文，也不是鼓励现实违规。

---

## 1. 使用原则

1. **批评制度性压力，不丑化具体人群**（教师、考生、家长均可被温和讽刺「话语」，但避免恶毒卡通化某一职业）。
2. **虚构学校与考点**：不要用可识别的真实中学名、真实考场布置图去一一复刻。
3. **「逃考」是寓言式玩法**：不提供现实作弊、伪造证件、逃票的可操作教程。
4. **张力来自被观看与时间**，而不是来自猎奇、血腥或羞辱玩法。

---

## 2. 高考语境（气氛参考）

- **时间感**：倒计时、铃声、夏日蝉鸣与空调声的反差；「一生一次」的话语重复。
- **物品**：答题卡、2B 铅笔、准考证（可用虚构编号）、矿泉水、透明文具袋——作场景道具即可。
- **空间**：课桌矩阵、讲台、前后门、遮光窗帘、黑板上的注意事项。
- **身体纪律**：禁止交头接耳、限制起身——转化为潜行教程的「第一次违规心跳」。
- **情绪**：恐惧、羞耻、兴奋、内疚可能同时存在；文案可短，让玩家自己感到矛盾。

避免：地域歧视、城乡对立脸谱、煽动厌学暴力。

---

## 3. 监考与「被看见」

- 监考在叙事里是**规则的眼睛**，不必写成自私反派。
- 玩法上用视野锥、巡视路线表达「被看见即失败」。
- 可以用广播里的标准用语（「认真作答」「遵守纪律」）制造压感。
- 避免真实监控品牌 UI 抄袭；用抽象摄像头指示灯即可。

---

## 4. 校园空间节奏

常见可用空间序列（简化、虚构）：

1. 教学楼走廊（喇叭、光荣榜海报纸可作装饰）；
2. 楼梯与消防通道（捷径与风险）；
3. 操场边缘 / 车棚（掩体增多）；
4. 门卫室与校门（最后闸门）。

设计时优先**可读路径**，不要复刻某真实校园平面图到可定位程度。

---

## 5. 高铁 / 地铁 / 机场的中国语境

这些空间在故事里代表：**把身体从考点坐标系统里拔出，接入国家尺度的流动**。

| 场所 | 可借用的感官 | 玩法简化建议 |
| --- | --- | --- |
| 高铁站 | 大屏车次、检票闸机、冷气与广播 | 购票 UI + 闸机触发器 |
| 地铁 | 换乘箭头、黄线、拥挤可只用音效暗示 | 站台到站触发 |
| 机场 | 安检队列、航班屏 | 安检用「放入托盘」一次交互即可，勿做真实违禁品教学 |

注意：

- 票面、站名可用虚构组合（「南城站」「临海站」），或使用通用地理感觉，避免伪造真实运营商标识体系导致误会。
- 不要模拟逃票技巧；玩家无票时给叙事失败或「去窗口补票」循环即可。

## 6. 地图与 OSM / ODbL 注意事项

### 6.1 为何提到 OSM

产品愿景希望关卡「参考真实地图结构」（道路骨架、街区尺度、车站相对位置），增强「真的在中国移动」的感觉。

### 6.2 现状

**仓库未包含 OSM 导入管线或真实城市可玩地图。** 属后期议题。

### 6.3 许可要点（接手查证用，非法律意见）

- OpenStreetMap 数据通常在 **ODbL** 下提供。
- 使用方式（直接服务、衍生数据库、截图、重绘）义务不同；**发布前必须核对** [openstreetmap.org/copyright](https://www.openstreetmap.org/copyright) 与所用导出工具的条款。
- 若基于 OSM **衍生**出可查询的数据库并公开，可能触发「同样开放」义务；若只是人工参考结构重新搭建游戏碰撞体，风险形态不同——仍建议法务 / 用户确认。
- 归因：在游戏 Credits / README 中保留 OSM 贡献者致谢（按当时条款）。

### 6.4 实务建议

- v0.2–v0.4：继续用占位街区；
- 需要真实结构时：先小范围（一个枢纽周边），先问用户是否接受 ODbL 合规成本；
- 禁止无归因地大规模扒取商业地图瓦片当游戏资源。

## 7. 可参考的情绪节拍（非抄袭具体作品）

- 「纪律空间」的安静 vs 「车站」的嘈杂；
- 个人呼吸声在潜行时被放大（音频后期可做）；
- 出校门阳光过曝一帧（画面后期可做）。

具体作品梗勿硬蹭版权角色；主题相近即可。
