## I. v0.2 考场 / 学校（Play 模式）

**准备**：英文输入法；先执行菜单生成（或确认场景已生成）。

### 考场

- [ ] 菜单 **EscapeExam → 生成考场场景** 成功（或打开已有 `ExamHall.unity`）
- [ ] Play 后可见课桌、监考、绿色出口与中文 HUD
- [ ] **Ctrl / C** 可蹲走，底部提示变化
- [ ] 走进监考视野 → 老师追赶；靠近抓住 →「被老师抓住了」→ 座位「被迫学习」→ 可再逃
- [ ] 利用课桌/柜子挡住射线后可通过
- [ ] 走到绿色出口 →「逃出考场」（若 Build Settings 含学校场景，应自动进入学校）

### 学校

- [ ] 菜单 **EscapeExam → 生成学校场景** 可用；或从考场成功自动加载
- [ ] 走廊内多名老师随机路点巡逻+追赶
- [ ] 被抓住会回检查点并短暂「被迫学习」
- [ ] 走到蓝色校门 →「逃出学校」→ 进入 **HubTown**（不是直接 TransitHub）
- [ ] **空格**可跳跃；**Esc** 可打开暂停菜单并保存/读取

### 回归

- [ ] OpenWorld 仍可 Play：走路 / F 上下车 / 黄圈「任务完成」
- [ ] Build Settings 含 OpenWorld、ExamHall、SchoolEscape、TransitHub、TravelMissions（可用 **EscapeExam → 将场景写入 Build Settings**）

## K. v0.4 追赶 / 存档 / 旅行门槛（Play 模式）

### 追赶与学习循环

- [ ] 考场有 ≥2 名老师，路点不固定两点往返（随机下一站）
- [ ] 发现后进入追赶，抓住后送回座位并显示「被迫学习」
- [ ] 学习锁定结束后可再潜行逃出

### 暂停存档

- [ ] Esc 打开暂停：继续 / 保存 / 读取 / 退出到标题 / 退出游戏
- [ ] 保存后改资金或场景，读取能恢复关键进度字段

### 现实城镇与地图

- [ ] 菜单 **EscapeExam → 生成现实城镇场景**；Build Settings 含 `HubTown`
- [ ] 逃出学校自动进 HubTown；按 **M** 可见地图景点/枢纽说明
- [ ] 黄圈任务增加资金；橙摊可买手机（资金不足有提示）

### 家庭留条

- [ ] 菜单 **生成家庭场景** 或 HubTown 绿门进入 `Home`
- [ ] 避开家长，桌上 E 留条（中文：自己赚钱出去旅游）
- [ ] 被家长发现 → 回屋内检查点；成功留条后可回城镇

### 购票门槛

- [ ] 未留条时枢纽窗口拒绝购票或提示先留条
- [ ] 无手机打开窗口 → 只显示「需要手机才能查看票价」
- [ ] 有手机可见票价；资金足够才能购票并扣款；检票进旅行

- [ ] OpenWorld 黄圈任务仍可用
- [ ] 旧 Input Manager；中文 UI；无 OSM / 联机依赖
