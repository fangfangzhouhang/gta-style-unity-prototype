## I. v0.2 考场 / 学校（Play 模式）

**准备**：英文输入法；先执行菜单生成（或确认场景已生成）。

### 考场

- [ ] 菜单 **EscapeExam → 生成考场场景** 成功（或打开已有 `ExamHall.unity`）
- [ ] Play 后可见课桌、监考、绿色出口与中文 HUD
- [ ] **Ctrl / C** 可蹲走，底部提示变化
- [ ] 走进监考视野且无掩体 → 出现「被发现了」并回到检查点
- [ ] 利用课桌/柜子挡住射线后可通过
- [ ] 走到绿色出口 →「逃出考场」（若 Build Settings 含学校场景，应自动进入学校）

### 学校

- [ ] 菜单 **EscapeExam → 生成学校场景** 可用；或从考场成功自动加载
- [ ] 走廊内有 1–2 名巡逻，复用视野锥
- [ ] 被发现会回检查点
- [ ] 走到蓝色校门 →「逃出学校」（若 Build Settings 含枢纽，应自动进入 TransitHub）

### 回归

- [ ] OpenWorld 仍可 Play：走路 / F 上下车 / 黄圈「任务完成」
- [ ] Build Settings 含 OpenWorld、ExamHall、SchoolEscape、TransitHub、TravelMissions（可用 **EscapeExam → 将场景写入 Build Settings**）

## J. v0.3 交通枢纽 / 旅行（Play 模式）

### 枢纽

- [ ] 菜单 **EscapeExam → 生成交通枢纽场景**（或打开 `TransitHub.unity`）
- [ ] Play 后可见橙色高铁窗口、蓝色闸机、机场值机占位与中文 HUD
- [ ] **无票**走近闸机 → 中文「请先购票」类提示
- [ ] 靠近窗口按 **E** → 面板选「G-自由01」（或其它车次）→「购票成功」
- [ ] **有票**走进闸机 →「检票通过」→ 自动进入旅行场景（需 Build Settings）

### 旅行

- [ ] 菜单 **EscapeExam → 生成旅行任务场景** 可用；或从枢纽检票自动加载
- [ ] 存在至少 3 个黄圈（西湖断桥 / 长城烽火台 / 黄山迎客松）
- [ ] 走进黄圈有中文完成反馈；三个都完成后有通关类提示

### 回归

- [ ] ExamHall / SchoolEscape / OpenWorld 验收路径仍可用
