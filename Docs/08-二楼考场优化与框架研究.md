# 二楼考场优化与框架研究

日期：2026-10-21（Asia/Shanghai）。基线提交：54a671e。本轮工程目录：`D:/Unity/gta-style-unity-prototype`。

## 本轮实现

- CampusWorld 的考场整体移到地面以上 4 米，玩家、检查点、教师、巡逻路点、考场出口同步抬高。路线：201 考场 → 二楼走廊 → 下行楼梯 → 一楼走廊 → 蓝色校门 → 城镇。
- 上层走廊接入宽 3.2 米的 20 级下行楼梯，每级高 0.20 米、进深 0.50 米；原先 0.40 米踏步超过角色 0.35 米步高，已替换。增设扶手、踏步前缘及楼层标识。
- 使用统一程序化桌椅，避免导入 FBX 单位造成巨大家具，也避免编辑器与运行时使用不同家具。桌面宽 0.70 米、深 0.50 米、顶面高 0.76 米；椅面高约 0.455 米。包含桌腿、置物板、椅背、椅腿、试卷。
- 窗框、墙裙、粉笔槽、考场标识、条形灯具补充校园辨识度。仍是程序化原型美术，尚未制作完整 Blender 资产与贴图。
- CampusHUD 统一绘制任务、交互、消息和操作栏；旧 HUD 在连通地图中仅提供消息状态，不再重复绘制。地图/暂停期间隐藏校园 HUD；消息横幅出现时隐藏交互提示。
- 家庭流程启动不再覆盖考场目标；城镇流程启动不再提前标记逃出学校/解锁地图。
- 通风口在二楼，终点仍在二楼走廊，并登记考场逃出；按 E 交互增加高度检查。教师抓捕增加高度判断，避免隔层抓人。
- 修正家庭检查点到真实屋内。
- 储物柜改用尺寸一致的程序化模型；移除超大书架装饰，旁楼教室装饰移离主考场。增加 33 个可复用持久材质与平坦环境光，已渲染复核编辑器预览无粉色缺材质。

## 验证与下一步

Unity batchmode 使用 `CampusSceneValidation.BuildAndValidate`：编译工程、生成地图、检查二楼出生/出口、桌椅尺寸、逐点检查门洞与楼梯到校门的地面和站立净空，再保存 CampusWorld。该检查不能代替真实 Play 的手感和追赶体验。

最终执行 `CampusSceneValidation.RunFinalChecks`，生成检查及自动 Play 启动均通过，日志包含 `CAMPUS_VALIDATION_PASS` 与 `CAMPUS_PLAY_VALIDATION_PASS`。Play 验证考场区域/阶段/目标未被家庭和城镇流程覆盖，角色稳定处于二楼，CampusHUD 组件存在。预览位于 `D:/Unity/CampusValidation/classroom.png` 和 `stairs.png`。多分辨率 HUD 视觉、完整移动/追赶/存档仍留待实际试玩。

建议按顺序做：

1. **实机走关与相机**：用站立/蹲走各跑一遍二楼至校门；检查镜头是否穿墙、教师追赶是否穿桌。本轮教师仍按简单直线移动，下一步采用 NavMesh、门口路点与正确楼层导航。
2. **潜行公平性**：目前蹲姿高度 1.15 米，标准课桌高 0.76 米，课桌不应被承诺为完整遮蔽物。增加书柜、讲台、隔断等真正遮视线的掩体，并校准蹲姿眼高、暴露累计和声响反馈。
3. **校园尺度与完整建筑**：当前房间沿用宽 24 米、深 28 米的原型空间。下一轮收紧教室与桌间距，重新校准巡逻速度/视距，再补一楼外立面、天花板、门框、灯光、校牌与花坛，消除悬空楼板感。
4. **模块化建模**：按米制尺寸制作可复用窗、门、楼梯、桌椅预制件；Blender 做倒角/UV、LOD 与碰撞，统一导出。用 Unity Profiler 测量再决定网格合并、材质实例和遮挡剔除。
5. **任务与存档**：把楼层、检查点和任务阶段做成明确状态数据，补存档恢复到正确楼层与区域的回归测试，再推进多人校园同步。
