# 校园总图、地面屏闪与摩托车

本轮在 `D:/Unity/gta-style-unity-prototype` 修改，Unity 2022.3，Built-in 管线。入口仍为 CampusWorld。未提交或推送。

- 屏闪根因：TownGround、YardFloor、WestGardenGround 顶面同高且交叠，另有重复房屋。替换为 240×400 米连续网格地形；建筑区底面 -0.12 米，独立铺装高于草地，交叉步道高差至少 2.5 厘米。草纹理按 2 米铺设，防止旧材质 90 倍重复叠乘网格 UV 造成摩尔纹。
- 校园围界 160×167 米（约 2.67 公顷），二楼考场保持原位置和完整逃脱通路；新增教学楼、图书馆、食堂、体育馆、椭圆健身跑道、15×28 米篮球场、运动草坪、门卫室和围墙。除已有考场/走廊/家庭等可玩室内外，新楼是封闭外观模型，尚未开放新室内玩法。
- 砖红主体与浅黄窗框、层间带、部分浅黄墙面，现有走廊也统一配色。建筑标牌使用深度测试，不隔墙显示。移除校门蓝色发光整面占位板。
- 地形外围平滑抬升约 0.6–2.8 米，教学区和主线保持平整；人物和骑行坠落边界随地图扩大，坠落仍返回检查点。
- 三栋 TownHouse 现在分别位于 (30,91)、(52,91)、(74,91)，每栋占地12×10米，横向留10米空隙。移除旧 BldgA/B/C 与同区域导入装饰楼的重复叠放。
- 校门口 GateMotorcycle 位于 (-19.5,59.5)，约2.2米长、0.8米把宽、0.84米座高。F上车，W油门、S减速、A/D转向、空格刹车，9km/h以下按F安全下车。第一人称骑行，HUD显示km/h。
- 以通勤摩托车手感设定：最高25m/s（90km/h）、加速3.5m/s²、刹车7m/s²、车与骑手合计220kg。是自动平衡的游戏驾驶控制，不是机械摩托仿真。连续碰撞检测，低摩擦轮胎接触配合横向抓地控制；下车根据地形射线和胶囊净空选点。

## 场景参考与下一步

本轮参考公开校园项目的院落和色彩照片，几何为程序化创建，没有导入参考图片或其建筑模型：

- 中国建筑设计研究院，北京三十五中新校园： https://cadg.com.cn/en/works/616/
- 零壹城市建筑事务所，义乌新世纪外国语学校，明黄校园与庭院： https://en.lycs-arc.com/current/2020-ad

下一步优先制作教学楼通往操场的可用入口和校内巡逻路径，再替换成具有砖缝、抹灰粗糙度、窗玻璃反射的PBR立面；为摩托车补骑手手臂、发动机声、前叉/后减震和仪表。运动场仍是小型健身场，不是标准400米田径场。不要把当前程序化原型描述为写实成品。
