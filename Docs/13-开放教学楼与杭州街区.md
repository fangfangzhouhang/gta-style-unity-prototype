# 开放教学楼、探索逃生与杭州街区体块

2026-10-22。本轮在现有 CampusWorld 中实现，仍为 Unity 2022.3.49f1c1、Built-in、旧 Input Manager。运行时无需地图 API、网络或付费插件。

## 新逃生流程

201 是教学楼二楼的一间真实房间，保留原有桌椅、老师和西门，增加朝向外廊的实体门洞。教学楼有三层可进入教室、有屋顶的开放外廊、庭院连桥、西楼梯和东侧双跑楼梯。教室不露天，庭院露天。

```mermaid
flowchart LR
    A[201考场查看疏散图] --> B[二楼203取得维修钥匙]
    B --> C[一楼用钥匙打开配电间]
    C --> D[关闭门禁警报]
    D --> E[校门控制箱解锁]
    E --> F[逃出学校并骑车进入城镇]
    B -. 东西楼梯可绕行 .-> C
    B -. 广播引开同层老师 .-> B
```

所有物件靠近后按 E 操作，统一由 CampusHUD 显示提示。钥匙、门锁、电源和校门要求正确顺序；隔墙不能拾取。校门有真实碰撞体，未解锁无法通过。搜集状态在本次运行中被抓后保留，退出游戏后暂不跨会话保存这组新谜题进度。

广播按钮引导同层、一定范围内且未进入追逐的老师调查声源，持续六秒；冷却八秒，不会隔层把所有老师召来。进入视野后仍正常追逐。三楼可探索和观察庭院，但主线钥匙流程使用一、二楼。

设计参考《你好邻居》的探索、物件解锁、追踪压力和捷径循环，未复制其房屋布局、素材或代码。当前是明确规则的声源调查和导航追逐，没有宣称实现其学习型 AI。

官方介绍：https://www.helloneighborgame.com/home-en

## 摩托车

相同速度和转向输入下，实际偏航转向乘数由 1.0 调整为 **1.30**。最高速度仍为25m/s（90km/h）。验证脚本比较两种乘数下的实际 Rigidbody 转角，而不只检查配置数字。

## 目录与清理

- `Assets/Editor/Campus/Tools/`：资产保存、调试显示恢复、无引用生成资源清理。
- `Assets/Editor/Campus/Validation/`：场景、玩法、骑行、教学楼、谜题、地块验证。
- `Assets/Scripts/Campus/`：运行时生成、校园流程、探索物件、摩托车与街区体块。
- `Assets/Resources/CampusTown/`：可编辑街区规划 JSON。
- `Assets/Art/GeneratedCampus/`：本轮场景仍依赖的生成网格、材质与导航数据。
- `Docs/images/`、`Docs/validation/`、`Docs/maintenance/`：实际渲染、验证记录和清理记录。

编辑器脚本及 .meta 一起移动，保持 GUID。清理工具先对保留场景、预制体、材质等求依赖，只清理生成目录内确认无引用的资源，并先备份到项目外的 CampusValidation/CleanupArchive。旧独立玩法场景、第三方源资源、技能、Library/Temp 和用户存档不在删除范围。生成流程中已去掉旧空装饰入口和不再使用的街区占位楼生成函数。

完整验证入口保持 `CampusSceneValidation.RunFinalChecks`，主项目最终日志 `D:/Unity/campus-v11-main-final.log`，独立验证日志 `D:/Unity/campus-v11-final.log`。结果归档至 `Docs/validation/campus-v11-result.txt`，清理记录在 `Docs/maintenance/cleanup-v11.json`。高架目前提供桥下通行和外观体块，未制作上桥匝道。
