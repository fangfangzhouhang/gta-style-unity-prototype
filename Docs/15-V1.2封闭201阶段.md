## 当前玩法

打开 CampusWorld 开始。201 前门始终实体锁闭，西侧门需要钥匙；四扇窗户保留原玻璃碰撞，旧通风口传送禁用。开场显示可用退格键跳过的主角独白与广播中文字幕。挂钟停止转动，当前没有配音素材，只有 AudioSource / AudioClip 接口。

后排有三件可调查物：检修试卷、旧考场座位表和密码柜。靠近按 E。试卷给出读取排号顺序，座位表给出对应数量；需玩家自己输入三位密码。输入错误不发钥匙；获得钥匙后还需前往西侧门按 E 开锁。前门不会随侧门解锁。密码面板可查看已经发现的两条线索；未调查的内容不提前揭示。

取得钥匙不自动开侧门，门的 Collider 和 NavMeshObstacle 在实际开门时同步禁用。侧门解锁后回接原 v11 的疏散图、203 维修钥匙、配电间和校门流程。因此**走廊、203、三楼和后勤仍不是 V1.2 的逐层门禁版本**，也未加入三名线索 NPC、图书馆谜题、Tab 手账或新城市骑行结章。

## 实现与兼容

- 新增 CampusExamChapter.cs：阶段 A 摆设、永久状态、密码界面、锁门恢复、字幕与音频接口。没有第二个 E 输入入口，全部通过 CampusEscapeDirector 分发。
- CampusEscapeObject.Action 只在原枚举末尾增加值，保留原场景序列化数值。
- CampusWorldBuilder 接入可重复生成模块；生成前备份到项目外 CampusValidation/V12Backup。没有把唯一手工内容留在会销毁的 LevelRoot 中。
- GameProgress / SaveData 增量增加 examChapter，保存已读线索、钥匙、侧门和开场事件；旧 JSON 缺字段时提供空状态，不删除经济、票券、家庭或旅行数据。
- GameProgress.SaveApplied 通知当前已加载的门恢复，兼容原 SaveSystem.LoadAndApply(false)。真实重载场景时由组件 Start 恢复门锁。
- 已有抓捕和回位不清除这组永久状态。后台冷却、密码面板和短字幕不保存。
- 原场景没有 CampusExamChapter 时，移动、独立考场出口与旧传送器保持原行为。没有升级 Unity 或更换输入/渲染管线。
- Unity 编辑器验证模式使用临时文件和独立 PlayerPrefs 键，不写正常玩家存档；退出验证模式后恢复原存档地址。

完整旧档迁移、章节有效检查点和后续区域恢复仍属第 5 步；不要把当前增量字段视为全章节存档已完成。直接从已离校旧档恢复到新校园的兼容流程尚未验收。
