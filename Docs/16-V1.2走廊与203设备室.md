# V1.2 第 2 步：二楼走廊与 203 设备室

基准提交 6541604，功能分支 feature/campus-v12-chapter-one。本阶段接续封闭 201，范围是主线 B/C，不是完整第一章。

## 可玩流程与规则

| 操作 | 前置条件 | 结果 |
| --- | --- | --- |
| 离开 201 | 取得钥匙并打开西侧门，实际跨过门平面 | 记录考场已逃出，首次走廊独白，进入二楼调查 |
| 与林同学交谈 / 读公告栏 | 201 侧门已开 | 得知 203 门旁储物柜有备用卡，可重复询问主线线索 |
| 调查储物柜 | 实际接近柜子并有视线 | 获得唯一通行卡，无需强制读完对白才能拾取 |
| 203 刷卡 | 已获得通行卡 | 同步解除前门 Collider 与 carving 障碍，开放设备室 |
| 调查维修记录 | 203 已开放，靠近工作台 | 获得三路设置说明：照明开、警报关、门禁供电开 |
| 操作三路开关 | 设备室已开放、尚未完成电路 | E 切换对应回路，颜色及提示显示状态 |
| 控制台确认 | 已读维修记录 AND 三路设置正确 | 永久开放东楼梯，播放滑门动作与本地合成提示音 |
| 上三楼 | 东楼梯已解锁 | 连续走上行梯到三楼；下楼仍需要后续图书馆阶段 |

初态是照明关、警报开、门禁供电关，不是随机密码。错误配置反馈原因，不打开门禁。确认成功后开关锁定，避免玩家反复断电把唯一通路关死。广播按钮沿用 v11 的有限距离、同层调查和冷却，不能无限距离吸引老师。

三名简单蓝色 NPC 使用 NavMeshAgent 在前廊靠教室墙面的小范围往返，周期性重新下发目标以恢复临时阻挡；保留中心通道。林同学提供可重复主线线索，其他两人提供巡逻/广播提示。NPC 不是老师，不触发抓捕。

203 移除原四组普通书桌和柜子，改为两侧工作台、工具架、工作台维修纸、三路墙面开关和独立确认台；中央留通道。设备室仍有原米制地板、墙体和天花板，没有继续扩大地图或更换渲染管线。

## 实体封锁

- 203 前门以通行卡解锁，后方由连续实体围护封闭，不能从后廊绕入。
- 其他二楼前排教室暂时关闭；后廊、房间之间的外侧空隙也被围护。
- 西楼梯始终封锁；东楼梯在完成回路前封锁。
- 完成回路只开放上楼方向；东侧下行门、下行梯侧面及中间平台边缘保持封闭。
- 二楼前廊与三楼周边、连桥增加全高透明围护，避免把低栏杆当成可靠门禁。玻璃不发光，有碰撞，不是空气墙或只靠 UI 拦截。
- 旧 ZoneTeleporter 在校园尚未逃出时不响应，通风口保持禁用；保留脚本和城镇/家庭传送器，后续按区域事实再开放。

“开放楼层”目前指连续可走的实际楼层，不代表任意区域从开局均可进入。教学楼仍能看到庭院和校园，主线区域按进度开放。

验证入口仍为 CampusSceneValidation.RunFinalChecks。使用独立副本 D:/Unity/CampusValidation/V09Project，重建前的主场景和导航备份位于 D:/Unity/CampusValidation/V12Stage2Backup。

保留原尺度、201 密码柜、四窗碰撞、坠落恢复、教师调查、地块和摩托车物理检查；原“开局楼梯全通”断言在新章节改为“锁定时断路、解锁后上楼通路完整、下楼继续断路”。新增检查：三名 NPC 接入 NavMesh、203 前后封锁、前廊高位碰撞、平台边缘/下行门实体阻挡、每个路线节点的实际楼层高度、无卡不能刷门、线索可重复、错误电路不能开门，以及解锁后门 Collider/障碍随存档恢复。

真实 CharacterController 路线完成 201 谜题 → NPC → 公告 → 无卡试门 → 卡 → 203 → 维修记录 → 错误回路确认 → 三开关 → 正确确认 → 广播 → 东梯 → 三楼。测试不通过时优先修改道具摆位和路线接近点，不停用角色碰撞或给 bot 增加穿墙权限。最终结果见 `validation/campus-v12-stage2-result.txt`：Unity 2022.3.49f1c1 编译和 Play 检查通过，A—C 实际移动交互路线 28.42 秒完成；201、走廊封锁、上楼/下楼导航、启动开关颜色、保存/读取与抓捕进度检查通过，摩托车转向实测仍为 1.300。未出现新增编译错误或测试异常；这个耗时是自动冲刺 bot，不是玩家解谜耗时。

仍需三次完整人工试玩，以及高低姿态、贴角跳跃、不同帧率下的防绕过检查。独立旧场景逐一 Play 和全章节旧档迁移尚未验收。
