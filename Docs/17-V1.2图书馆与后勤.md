起始提交 cf36446，功能分支 feature/campus-v12-chapter-one。沿用 Unity 2022.3.49f1c1、Built-in、旧 Input Manager。保留密码面板鼠标修复与 Enter 确认，不更换移动、相机、驾驶或教师状态机。

## 阶段 D：图书馆

三楼原 304/305 的普通教室替换为 22×12 米图书馆，有两处前门、两排双面书架、阅览桌、三组编号档案柜和封闭天花板。书架两侧、前后有绕行空间；完成档案调查后，后门连通原有中庭外廊，通过 303 返回前廊，形成可回访的实体环路。封闭未开放教室的前门及房间间的空隙，避免从三楼缺口跌到低层跳关。

谜题规则固定，不随机：书目索引说明紧急档案按现行检修手册书号归档；阅览桌旧记录指出 024 已废止、142 属于食堂，现行教学楼门禁使用 086。玩家调查两处环境物件后，在 A·024、B·086、C·142 三柜中选 B·086。

选错只给出核对提示，不发奖励、不消耗线索。未读索引或未读旧记录时，即使选对也会提示先核对资料。正确档案一次性授予紧急说明和维修钥匙，同时开放东西下楼通道及图书馆后门/303 回访门。重复查看不重复发奖。

两个可用下楼选择：沿东梯直接到后勤前廊；回到二楼后走已解锁的西梯。图书馆后门环路可以回看旧线索；所有路径保留原有楼板、天花板和防跳落围护。

## 阶段 E：后勤与紧急模式

下楼后可探索后勤前廊和配电间入口，庭院前门与西侧通道初始实体封闭。其余非开放教室锁闭，后门与楼梯侧面封闭，不能提前走到校园外。

| 机关 | 条件 | 开放结果 |
| --- | --- | --- |
| 东侧下行门 / 西楼梯门 | 203 回路完成，正确检索图书馆档案 | 可到一楼，可返回旧楼层 |
| 图书馆后门 / 303 回访门 | 正确检索档案 | 中庭外廊实体环路 |
| 一楼 102 配电间 | 紧急说明 AND 维修钥匙 | 门 Collider / NavMeshObstacle / 可见表现同步解除 |
| 配电开关 | 说明 AND 钥匙 AND 配电间已开 | 永久启动紧急模式 |
| 庭院前门 / 西侧通道 | 紧急模式已开 | 两条庭院出口可选 |
| 校门 | 本阶段未接通最终控制流程 | 保留实体门禁，不能直接判定离校 |

启动紧急模式后，选定的一楼普通灯降到原亮度 12%，三盏暖色应急灯亮起，播放异常广播中文字幕，并以 22 米范围、同层规则让老师调查（已追逐的老师继续追逐）。新后勤老师沿前廊巡逻；已有教师 FSM、遮挡检测与导航系统复用。灯光变化不禁用楼板、碰撞体或 NavMesh 数据。

所有条件及操作继续通过同一个 CampusEscapeDirector 输入入口、距离和视线检测分发，没有新增第二个读 E 的脚本。当前广播为中文字幕，没有配音资源或语音演出。

## 自动验证覆盖

保留并串联前两阶段与密码鼠标抢占检查。新路线实际移动完成索引、阅览桌旧记录、错误柜、正确柜、后门环路、303 回访、东梯下楼、配电间、开关及进入庭院；每个节点校验实际楼层高度。

在正确柜实际可交互的位置分别取消索引/旧记录，验证缺任一项不能获得说明或钥匙；在配电间门口分别取消钥匙/说明，验证联合条件，而不是只查布尔配置。另检初始庭院前门、西侧通道和配电间的真实碰撞，以及上楼尚未解锁时不能从图书馆到一楼。

完成紧急模式后核验应急灯亮度、老师响应、开放楼梯导航、校门仍不能过关、保存/读取后的门及障碍状态、抓捕后保留图书馆进度。重复使用已完成配电开关不重置状态。运行时另渲染应急前廊，静态渲染图书馆。

首轮测试暴露阅览桌接近点仍选中索引牌，调整到可接近书页的位置；下楼测试暴露原整块侧面围护挡住地面出口，改为地面通口加上层围护，保留二楼防跳落；踏步节点用实际 4.2 米台阶高度，避免把正常跨台阶误报为楼层错误。

最终自动验证通过，完整连续路线 65.97 秒，日志含 CAMPUS_LIBRARY_SERVICE_RUN_PASS 和 CAMPUS_STAGED_CHAPTER_COMPLETE。结果归档于 [验证记录](validation/campus-v12-stage3-result.txt)。自动 bot 的冲刺时间不能代表首次玩家的解谜耗时。三次完整人工试玩、逐个旧独立场景 Play、贴角跳跃/蹲伏与极端帧率验收仍未完成。
