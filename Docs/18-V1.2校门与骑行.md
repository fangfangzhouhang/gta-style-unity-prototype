原 SchoolGate 触发器曾覆盖校门内侧；现移至门外 z54.6，另外由 TryDepart 校验真实位置，避免开门时还没走出去就算离校。步行到城镇路段不算骑行完成。操作仍为 F 上车、W/S 油门 / 减速、A/D 转向、空格刹车、低速 F 下车。

校门不是隐藏 UI 锁：同一状态恢复实体碰撞、导航障碍、5 米横移表现、控制箱颜色和交互文案。开门动画时长 0.8 秒；读档直接恢复最终开门姿态。已开控制箱从 Nearby 候选移除，重复按 E 不重复触发离校或奖励。无新增 E 监听器，继续经 CampusEscapeDirector 分发。

原摩托车仅增加 RideUnlocked 门槛，不改驾驶参数。没有 CampusDepartureChapter 的旧场景仍可正常骑乘。存在新章节时，在实际离校前 CanMount 与 TryMount 都拒绝骑乘；开门本身不足以骑车。

离校后先显示骑行目标，完成后恢复原 Hub 回家留条、购买手机、赚钱和旅行流程。旧 ZoneTeleporter、ScenePortalInteract 与 CampusFlow.TryLoadScene 都在 completed 前阻止捷径 / 场景跳转；完成后原留条、手机和购票条件仍保留。

## 存档与兼容

GameProgress / SaveData 增量加入 departureChapter { gateOpen, departed, completed }。旧 JSON 缺少字段时初始化为空状态。SaveApplied 恢复门禁与骑乘权限，并同步 CampusFlow 的离校状态；首次离校的中文字幕由 departed 永久标记防重播，章节完成由 completed 防重播。没有合法配音素材，因此当前离校与完成为中文字幕，未添加语音。

第 5 步仍需统一事件字幕接口、Tab 手账、旧档迁移规则、跨场景的完整位置 / 检查点恢复。当前不承诺旧 v11 离校存档自动迁移到新第一章末尾。

初次连续验证暴露校门门板被采入静态导航烘焙的问题：即使运行时关闭障碍，底层导航仍有永久断口。CampusNavigation 现在从静态采集中排除 carving 动态障碍，保留它们运行时雕刻与恢复。庭院路线通过西侧 z41 的既有通口，未删除围墙来迁就测试。最终完整自动路线通过，用时 85.36 秒，其中离校后的骑行与刹停下车段 5.58 秒。门外实际触发、14 项缺一拒绝、开门后导航连通和状态读档检查通过，见 [验证结果](validation/campus-v12-stage4-result.txt) 与 [实际校门渲染](images/campus-v12-stage4-gate.png)。自动 bot 耗时不代表首次解谜体验。三次完整人工试玩、实体鼠标交互、极端帧率、跳跃贴角绕行、旧独立场景的完整流程与手感回归仍需人工完成。
