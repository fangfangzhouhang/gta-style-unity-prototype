## 1. 节拍表（教 → 练 → 考 + 假安全 + 出口布置窗）

**节奏原则（DESIGN 已写死）**：约每 **20–40 秒** 应有一次可解释的选择（再观察 / 移动 / 诱饵位置 / 绕行 / 抬一档还是撤）。这是观察指标，不是强制事件计时器。

**时长目标（开放项，留给后期调参）**：

| 档 | 含义 | 本轮态度 |
| --- | --- | --- |
| 10–15 分钟 | 熟练 / 跳广播 / 纯潜也可满意离场 | **允许**；不得为凑时加锁 |
| 15–25 分钟 | DESIGN 首玩目标区间 | **目标**，不强制本轮夹具验收 |

| # | 节拍名 | 假设累计 | 空间 | 玩家在学什么 | 20–40s 内的目标选择（示例） | 张力 |
| --- | --- | --- | --- | --- | --- | --- |

### 节拍挂接（骨架不改）

```text
开场观察窗(B0) → 教试铃(B1) → 练主环(B2) → 假安全/近路(B3–B4)
  → 广播(B5) → 出口前喘息(B6) → 布置窗抬栅(B7) → 实际离场(B8)
```

可选侧翼（**实现不在本 P0 代码切片**；设计已拍板）：

- **S 教具储藏**：挂在 B3 rest，隔离学门楔（窥视 + 卡卷纸架）。
- **H 卷纸检修夹道**：挂在 B6–B7，可选接近/撤退；**不**绕过三档卷栅。

## 2. 短失败证据句（手册体 · 1–2 行）

原则（与 DESIGN「失败、恢复与信息」一致）：

- 只陈述**实际最后证据**，不剧透未发现房间解法。
- 不虚构「因为你跑步」这类未验证归因。
- 下一局能立刻改计划：哪种声危险、哪个转角仍可见、哪段退路没留。

### 2.1 被抓（catch）

按最后证据选 **一条** 主句；第二行可选补「进度保留」类安心信息（卷栅档 / 近路 / 广播配置已保留时才写）。

| 情境（实现侧已有或可观测） | 短失败证据句（可直接进 UI / 手册） |
| --- | --- |
| 门玻璃 / 廊角清晰目击后贴身 | 转角那边他还看得到你。下一次先断视线，再换路。 |
| 追逐中同侧莽开正门「突脸」 | 门一开他就在对面。先听脚步，再开这扇门。 |
| 站在已响的诱饵旁围观 | 铃声把两边都叫来了——包括还站在铃边的你。 |
| 搜索态检查最后目击点附近遮挡 | 他在你刚才消失的地方多停了一会儿。换一个遮挡再等他走。 |
| 出口前室操作点被跟入 | 链声把人引到了门口；你抬栅的时候退路还空着。 |
| 急关门 / 门闩类清晰噪声被定位 | 那一声门响够他走到门口。关门能挡眼，挡不住已经记下的方向。 |
| 笼统兜底（证据不足时） | 他确认你在这一带。先听脚步离开，再从另一条路走。 |

安心第二行（有进度时，择一）：

- `已升起的卷栅档位保留。`
- `运卷近路仍开着。`
- `广播面板的设置还在。`

### 2.2 计时器误用（timer misuse）

| 情境 | 短失败证据句 |
| --- | --- |
| 手持响铃被看见 / 追上 | 铃在你手里响的时候，声源就是你自己。 |
| 铃放在自己正要穿越的必经口 | 他循着铃挡住了你刚才选的那条路。换一个声源点，或等他开始调查再过。 |
| 追逐中仍指望铃声打断 | 他已经看见你了；铃声拉不走正在追的人。先断视线。 |
| 铃停后立刻从声源点探头 | 调查还没结束。等他俯身看完、转身离开，再从另一侧走。 |

### 2.3 广播误用（broadcast misuse）

| 情境 | 短失败证据句 |
| --- | --- |
| 外放选在 **E**（近出口）且自己同时在抬栅 | 东廊的喇叭太近了——链声和广播把他一起引到出口前。下次外放考场或印务。 |
| 未停循环就外放，环境嘈杂难读教师 | 「还有一分钟」还在响，脚步被盖住了。先停掉循环，再听他往哪边走。 |
| 在 B 清玻璃前站立调面板被看见 | 播音间的玻璃挡不住站着的人。蹲到柜后，或先看东廊有没有人。 |
| 测试后自己冲进刚选的外放区 | 你刚把声音送到这里，又自己走进声源区。等他去调查，你走另一条。 |
| 分区选错但可撤回（引导，非责骂） | 喇叭在别的区响。面板可以改，不用锁在错误上。 |
