## 1. 体验目标（本轮要修的问题）

依据 COLLAB / PROJECT_STATUS / KNOWN_ISSUES：

1. **危险可读性变弱**：Alert UI 已关，玩家只能靠剪影/步态/停步/脚步声读状态——开场观察窗必须更强（**拟实现**文案/引导强化；AI 参数不改）。
2. **谜题浅 / 时长塌**：熟练几分钟可出；需要教→练→考 + 假安全 + 出口布置窗，而不是加锁（**设计节拍**；灰盒 S/H 已给可选深度）。
3. **组合未讲清**：计时器、广播、门楔、S、H 是否真形成有趣 COMBO——见 §3。
4. **失败反馈弱**：被抓后多为笼统句，难以指导下一次（**拟实现** · 任务卡另文）。

硬边界（重申 · **自由回路表语境**）：无垫钥 collectathon、无第二敌人、无黑箱学习 AI、不把 Godot 章扩成 Unity 大校园。**注意**：gated 已批 **S 必经**（H/楔仍可选）——见 gated 文；本表代码描述未改前仍按「S 可选」写实。

## 2. 节拍表（首玩 10–15 分钟假设窗）

节奏原则（DESIGN）：约每 **20–40 秒** 一次可解释选择——观察指标，非强制事件计时器。

### 3.4 组合裁决（一段话）
