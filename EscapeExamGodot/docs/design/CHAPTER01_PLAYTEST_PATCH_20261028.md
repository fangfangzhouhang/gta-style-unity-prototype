## 3. P0 · Cabinet UX（假「柜」→真开柜再给钥）

### 3.1 问题

世界钥是**直接 E 拾取**，文案却写「柜 / 第三格 · 空」。玩家按「柜」预期去开 → **打不开** → 体验假。ark：「钥匙存储柜打不开」。

### 3.2 目标交互（key_id 链不变）

| 钥 | 位置（叙事） | 新交互流 | 给钥后 | `key_id` |
| --- | --- | --- | --- | --- |
| **K1** | C · 讲台 **第三格** | 对准讲台第三格/抽屉 → E **打开**（短动画或状态切换）→ **再**授予 K1 | 格内空态可读；再次 E = 读空 caption | 仍 **k1** → Classroom |
| **K2** | J · 洗手池下柜 | 若同为假柜：同样 **先开柜 → 再给 K2** | 柜空态可读 | 仍 **k2** → Storage |
| **K3** | S · 教具柜（若同模式） | 先开柜 → 再给 K3；**禁止**把 K3 放在 G 锁后 | 空态可读 | 仍 **k3** → GateAntechamber |

> 若 K2/K3 实机已是真柜或 ark 只点了讲台柜：优先修 **K1 讲台第三格**；K2 洗手池柜 **同构一并修**（防「一个真一个假」）。

### 3.3 文案 / Prompt（草案 · 可微调声调，语义锁定）

| 态 | Prompt / 短读（中文） |
| --- | --- |
| 关 · 未开 | 「讲台第三格 · 拉开」 / 「洗手池下柜 · 打开」 |
| 开 · 有钥 | 「取出值班钥」 / 「取出教具室钥」（确认一次即可进包） |
| 开 · 已取 | 「讲台第三格 · 空」 / 「洗手池下柜 · 空」（与现 empty_caption 对齐） |
| 指向短读（C） | 保持既有「第三格」指向；勿写第二套藏钥点 |
| 失败/拒 | 无钥开 Classroom：「门扣着 · 要值班钥」类既有拒句；本票不改失败证据全文 |
