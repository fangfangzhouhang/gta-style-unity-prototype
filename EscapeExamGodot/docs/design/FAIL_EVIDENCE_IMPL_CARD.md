## 1. 被抓（catch）行

### 1.1 门玻璃 / 廊角清晰目击后贴身

| 项 | 内容 |
| --- | --- |
| **文案** | 转角那边他还看得到你。下一次先断视线，再换路。 |
| **状态** | **拟实现** |
| **对应实际游戏状态** | `teacher.state == "chase"`（或刚由目击拉满 suspicion 进入 chase）且贴身距离触发抓捕；`evidence` 当前常为目击固定句。 |
| **可观测触发** | `can_see_player() == true` 累积至 chase；`_flat_distance(player) < 0.72` → `Game.caught`。**kind 建议**：`los_corner` **待开发确认**（可用：抓捕前 `visible` 为真且非门内突发）。 |
| **误判可能** | 实际是声诱调查中途突然对上视线——若只报「转角」，玩家会以为没被声源连累。 |
| **回退文案** | 他确认你在这一带。先听脚步离开，再从另一条路走。 |
| **能否改善下次** | 能：提示断视线 + 换路，不要求新道具。 |

### 1.2 追逐中同侧莽开正门「突脸」

| 项 | 内容 |
| --- | --- |
| **文案** | 门一开他就在对面。先听脚步，再开这扇门。 |
| **状态** | **拟实现** |
| **对应实际游戏状态** | 玩家刚 `door.set_open(true)` 后短窗口内进入贴身抓捕；教师在门另一侧已追逐/调查。 |
| **可观测触发** | **待开发确认**：需门交互时间戳或 `trace("door...")` 与 caught 间隔；现无现成 `last_door_opened_by_player`。 |
| **误判可能** | 门开很久后在走廊中段被抓仍报「门一开」→ 假归因。须限时（如开后 ≤2s）且双方近门。 |
| **回退文案** | 转角那边他还看得到你。下一次先断视线，再换路。 |
| **能否改善下次** | 能：听脚步再开门——与 Alert 关闭后的耳听策略一致。 |

### 1.3 站在已响的诱饵旁围观

| **可观测触发** | `timer.state` / `timer.global_position` 距离；`heard_id` 含 `ring_*` 或 caption「计时器铃声」。**部分可观测，聚合逻辑待开发确认**。 |
| **误判可能** | 广播外放也被 caption 成铃类——须用 `source_id == "timer"` 区分 broadcast。 |
| **回退文案** | 他循着声音来到了这里。换一个声源点，或等他开始调查再过。 |
| **能否改善下次** | 能：诱饵与自身分离。 |

## 2. 计时器误用（timer misuse）

> 下列可在「因计时器相关证据被抓」时优先于笼统目击句。

### 2.1 手持响铃被看见 / 追上

| 项 | 内容 |
| --- | --- |
| **文案** | 铃在你手里响的时候，声源就是你自己。 |
| **状态** | **拟实现** |
| **对应实际游戏状态** | `timer.held == true` 且 `timer.state == "ringing"`（或 countdown 末期）时被抓。 |
| **可观测触发** | `ExamTimer.held` + `state` **已实现**。 |
| **误判可能** | 手持但未响（idle）被抓——不可用本句。 |
| **回退文案** | 铃声把两边都叫来了——包括还站在铃边的你。 |
| **能否改善下次** | 能：先放置再响，或停铃再移动。 |

### 2.2 铃放在自己正要穿越的必经口

| 项 | 内容 |
| --- | --- |
| **文案** | 他循着铃挡住了你刚才选的那条路。换一个声源点，或等他开始调查再过。 |
| **状态** | **拟实现** |
| **对应实际游戏状态** | 教师 investigate/chase 在计时器位置与玩家路径之间；玩家试图穿过声源走廊时被抓。 |
| **可观测触发** | 几何关系 **待开发确认**（无现成「必经口」图）；弱化版：抓捕点距响铃 < 阈值且教师从铃处来。 |
| **误判可能** | 高：任意铃旁死亡都可能像「挡路」。宁可少触发，多用 2.1/1.3。 |
| **回退文案** | 他循着铃来到了这里。等他俯身看完、转身离开，再从另一侧走。 |
| **能否改善下次** | 能（若触发准）：改声源点或等调查。 |

### 2.3 追逐中仍指望铃声打断

| 项 | 内容 |
| --- | --- |
| **文案** | 他已经看见你了；铃声拉不走正在追的人。先断视线。 |
| **状态** | **拟实现** |
| **对应实际游戏状态** | `teacher.state == "chase"` 期间玩家仍 `timer.arm()` / 铃 ringing；随后被抓。代码上 chase 中 `hear_noise` 直接 return——铃确实无效。 |
| **可观测触发** | chase 中 timer 激活 flag **待开发确认**（可在 arm 时若 state==chase 记 `timer_armed_during_chase`）。 |
| **误判可能** | 追逐前就响的铃延续进 chase——应确认「chase 期间有新的 arm/ring 脉冲」。 |
| **回退文案** | 转角那边他还看得到你。下一次先断视线，再换路。 |
| **能否改善下次** | 能：教规则边界（DESIGN 已写，反馈未挂）。 |

### 2.4 铃停后立刻从声源点探头

| 项 | 内容 |
| --- | --- |
| **文案** | 调查还没结束。等他俯身看完、转身离开，再从另一侧走。 |
| **状态** | **拟实现** |
| **对应实际游戏状态** | `state == "investigate"` 且距 `noise_target` 近、玩家从遮挡探出被看见转追后抓。 |
| **可观测触发** | `investigation_dwell` / `state_time`；玩家由不可见→可见。 |
| **误判可能** | 调查已 return 仍报本句——须 state==investigate。 |
| **回退文案** | 他在你刚才消失的地方多停了一会儿。换一个遮挡再等他走。 |
| **能否改善下次** | 能：等调查结束。 |
