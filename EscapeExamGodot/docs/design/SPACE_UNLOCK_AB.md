## 0. 两种幻想分别指什么

### 方案 A · 现有 Godot「自由回路」（**已实现基线**）

- 开场即可进入 **W—J—E—M—W** 主环；教师沿主环巡逻。
- **不**要求先解谜才获得第一次可执行逃生路线（`DESIGN.md` 写死）。
- 空间奖励型解锁：
  - **C↔M 运卷闩**：从 M 开，永久近路（可选优势，也扩大教师可达）。
  - **广播**：知识/策略解锁，不开门。
  - **S / 门楔 / H**：纯可选侧翼（P1 灰盒 **已实现**）。
- 完成条件：三档卷栅后实际离场；广播非硬前置。

### 方案 B · 早期「教室封闭 + 逐层解锁」幻想（**未实现 · 已否决/搁置**）

- 玩家印象中的 RE2 / 部分 Hello Neighbor 开局：起点房间或第一段走廊**暂时封死**，靠线索/道具/机关**按层打开**下一区。
- 与早期 Unity 校园方向的亲缘：层层锁门、拉长「逃出学校」动机（**不同产品范围**；不可未经批准塞进本章）。
- 在本章语境下的可能变体（均 **未选 / 否决或搁置**，除非 ark 重开）：
  - **B1**：C 正门初锁，必须用计时器声诱老师离开后再…（仍易变成伪钥匙）。
  - **B2**：主环存在，但 E 或 G 方向初封，需印务/广播进度才开（把「早看出口」改成「晚见出口」）。
  - **B3**：保留主环，仅把「心理封闭」做成叙事（门可开，但强引导先观察）——接近 A 的软方案。

> **历史预告（已由 ark 定案）**：曾默认建议 **A**；现已 **「用户已批准」A**。B3/B2/B1 均未选 → 否决或搁置，除非 ark 重开。不推荐 B1 式硬锁。

## 1. 对比表

| 维度 | A · 自由回路（当前） | B · 教室封闭 / 逐层解锁 |
| --- | --- | --- |
| **玩法感受** | 开局就有「可绕行的环」；压力来自巡逻与声线，而不是门禁。玩家很快看见出口方向，目标清晰。偏 *「设施在我手里」*。 | 开局压迫感更强（真封闭）；目标变成「下一把锁在哪」。易出现 *找钥匙焦虑*；若锁有提示则像 RE2 文件流，若无提示则像垫时长。 |
| **节奏** | 前 3–7 分钟可完成主环认知；时长塌的风险来自**谜题浅**而非迷路（KNOWN_ISSUES）。假安全靠 M rest / 可选 S，不靠新房间。 | 前段必然更长；若每层一锁，20–40s 选择变成「找交互点」。熟练玩家仍可能速通，但首玩易拖且失败于「卡关」而非「被抓学习」。 |
| **工作量** | **已完成**主环与可选侧翼；本轮策划只补节拍/失败句/引导。 | 需改门初始 `locked`、导航链接、巡逻可达、教程文案、软锁检测、存档字段；可能重烤导航；回归夹具大增。与「不重写通关骨架」冲突风险高。 |
| **风险** | Alert 关闭后危险可读偏弱；熟练过短；近路战术价值待验。 | 违反「无意义多重门锁」「不能要求先解谜才有逃生路线」；易与 S/H「可选」哲学打架；把 Godot 章拉向 Unity 范围 creep；打回成本高。 |
| **与现有代码兼容** | **高**：`door.gd` 快捷闩、主环开口、S/H 可选均按 A 建成；48 夹具含无楔离场。 | **低–中**：B1/B2 要动初始拓扑与教师巡逻假设；`route_trial` / acceptance 路径失效；`DESIGN.md` 拓扑段需 ark 批准重写。B3 兼容高（只加引导，不锁门）。 |

## 2. 对玩家体验的具体损益

### 若维持 A（**「用户已批准」**）

| 玩家得到 | 玩家失去（相对 B 幻想） |
| --- | --- |
| 立即有意义的绕行/观察选择 | 「第一扇门打不开」的经典封闭惊悚钩 |
| 出口早曝光 → 动机清晰 | 晚见出口的「揭幕式」 |
| 与计时器/广播/楔/H 的组合实验空间从早期就存在 | — |

**如何补 A 的「封闭感」而不改拓扑（拟实现，非锁门）**：

1. 开场强制低柜观察窗（B0）——心理封闭。
2. 正门玻璃剪影 + 停播前嘈杂 —— 听觉压迫。
3. 失败证据句 —— 被抓后仍有学习，而非换钥匙。
4. 可选 S 作为「安全教室感」的真封闭小课室。

### 若改 B1/B2（不推荐除非 ark 强要）

| 玩家得到 | 玩家失去 |
| --- | --- |
| 更强的开局门禁仪式感 | DESIGN 核心句「初始即有回路」 |
| 可能拉长首玩钟面时间 | 「加锁凑时」差评路径；可选系统变必做 |
| — | 已实现 QA 门禁与脚本路线成本 |
