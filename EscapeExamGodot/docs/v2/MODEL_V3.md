分支：`claude/v2-model`（基于 V2 集成 tip）。未合 main，未 push（本机无 git 凭据，走 bundle 交付）。

## 这次做了什么

V2 只改了材质与几个几何块（用户反馈属实："人物基本没变"）。V3 用 Blender 真建模重做教师全身，
替换 `scenes/actors/teacher.tscn` 中 `$Visual` 的全部几何：

- 模型文件：`assets/models/teacher/teacher_model.glb`（约 457 KB）
- 生成脚本：`tools/model_teacher.py`（Blender 4.2 无头运行，改参数后可一键重生成）
  `blender --background --python tools/model_teacher.py -- assets/models/teacher`
- 接入方式：teacher.tscn 的 `Visual` 节点改为实例化该 glb；节点名/层级/枢轴与旧版完全一致
  （LeftLeg/RightLeg 髋 1.05、LeftArm/RightArm 肩 ±0.325/1.80、Head 2.02），
  teacher.gd 的程序动画（摆臂、转头）与 prologue 的 `Visual/Head` 引用零改动兼容。
  注意：肩枢轴由旧版 ±0.34 内收至 ±0.325（消除肩部脱节），属模型内部坐标，不影响任何脚本。

## 设计标准（参考来源与取舍）

按用户要求以《第五人格》监管者形象为**质量标准**参考（立绘：摄影师·约瑟夫、红夫人·玛丽），
只借标准、不借皮（延续设计圣经"借信息层不借皮"与自有风格要求，角色本体仍是本项目的监考教师）：

借的四条标准：
1. 修长比例（约 8 头身）+ 强收腰 + 下摆外张——剪影 10 米外可辨；
2. 苍白空白脸 + 深眼窝——"没有表情"比"狰狞表情"更贴"终场秩序"的公事公办；
3. 一个角色一个强记忆点道具——本项目用红笔 + 密封试卷筒 + 腰间钥匙串（均为监考身份物件）；
4. 一主色压全场 + 金属点缀——大衣深灰青为主，钥匙金属高光为唯一亮点材质，印章红仍只属红笔/标记。

新模型部件（均为成形网格，不再是 BoxMesh）：塑形头颅（下颌收分、下巴微前凸）、
深色杏仁眼、蹙眉、圆框眼镜（镜圈+鼻桥+镜腿）、礼貌微笑弧线、发帽+斜扫刘海+鬓角、耳朵、
立领、衬衫三角+领带、翻领、纽扣、收腰长大衣+腰带环+外张长裙摆、双段微弯袖+袖口、
长掌+指+拇指、红笔（笔尖/笔身/笔帽环车削件）、文件夹、试卷筒（筒身+卷边环）、
钥匙串（环+三把带齿钥匙）、收分裤腿、圆头皮鞋。材质在 Blender 内以 Principled 参数
沿用 V2 调色，glTF 携带至 Godot。

## 已知问题与留观

1. Blender 测试渲染中左髋部的暗色"花瓣"影：已用排除法确认不是穿模、不是多余几何
   （去大衣渲染无此物、去附件渲染仍在、大衣三件套单独渲染干净），系测试场景太阳角度下
   袖子在衣身上的投影；游戏内截图无此现象。勿再追。
2. 裤腿顶端止于髋下（v≈0.95）：收腰段两椭圆截面偏心相交会穿模，只缩半径不够，必须降顶（脚本内有注释）。
3. 手部仍是程式化"长掌+指块"，未做分指；面部无表情变化（设计即如此：空白脸）。
4. 课堂场景内教师正面偏黑是 V2 已知校准项（脸部可读性），属灯光/曝光数值问题，不在本次建模范围。
