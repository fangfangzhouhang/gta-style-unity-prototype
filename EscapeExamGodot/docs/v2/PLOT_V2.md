## 3. 新决策层：探头 × 粉笔 × 计时器

| 工具 | 时间结构 | 风险 | 典型决策 |
| --- | --- | --- | --- |
| 探头 Lean | 持续（按住） | 只暴露头部（感知侧按 `lean_exposure()` 折算，集成待办） | 门角/柜角先探再走，替代「整个人出去赌」 |
| 粉笔 | **即时**（落地即响，reach 9） | 声源离手即成立，但只有 2 支、响一次 | 追逐/调查中临时改向、抬栅被打断时补位救场 |
| 计时器 | **延时**（3s 预备 + 8s 铃，reach 28） | 布置成本高（要接近、要回收） | 计划性设局：留 C 诱走、人在 M 包抄 |
| 广播 | **远程可重复**（面板） | 要先抵达 B 并操作，站立调面板可被清玻璃看见 | 终局前的远程声源与真静开关 |

设计意图：粉笔不是「第二个计时器」——它补的是**即时性**这一格。四者构成「现在 vs 定时 vs 远程」的时间三角，决策密度优先于道具数量。

## 4. 红笔标记：进程量与落点

- severity ＝ `gate_stage`(0–3) + `teacher_summoned`(0/1) + `shortcut`(0/1) + `loop_stopped`(0/1) + `min(caught_count, 2)`，需要标记的门数 ＝ clamp(severity, 0, 门总数 5)。
- 落点：按门名字母序（Classroom → GateAntechamber → Print → Shortcut → Storage）逐个补齐——同一进程下落点稳定、可复现，方便玩家形成「他先查哪扇门」的阅读习惯。锚点＝门框右柱上部（局部 (0.48, 2.02, 0.13)），奇偶交替勾/圈两种形。
- 语义（与圣经 §2 招牌意象一致）：**勾＝他检查过；圈＝他在怀疑**。本轮以序号奇偶交替呈现两种形；「圈只落玩家常走门」需要教师域的路线热力图数据，列集成待办（见 §6），不得冒充已实现。
- 存档：标记不持久化，按 progress/caught_count 随时重建；新一局/读档由 0.25s 轮询自动对齐（多删少补），trace `red_mark_added{door, stage}` 可复盘。

## 5. 正面处理：「钥匙链 = 节拍器，不是清单」

**问题陈述**：`CHAPTER01_GATED_PROGRESSION_REDESIGN` 已批准并落地的最小钥匙链（K1→`Doors/Classroom`、K2→`Doors/Storage`、K3→`Doors/GateAntechamber`，S 必经）解决了旧自由回路「无目标感」的问题，但它有一个已知的滑坡风险：若每把钥匙只是「柜子里的下一把钥匙」，它就退化成 DESIGN 当初反对的三把钥匙收集清单——玩家记住的是位置，不是局势。

**改造原则（V2 定版）**：一把钥匙只有同时改变**空间**与**威胁**才配存在。逐把绑定如下：

| 钥匙 | 空间变化（已实现） | 绑定的威胁/局势变化 | 状态 |
| --- | --- | --- | --- |
| K1 考场值班钥 | C 由禁锢变出口（`Doors/Classroom` 解锁） | **教师上场**：首次开门延迟 2.5–4s 召唤至走廊巡逻起点 + 循门声调查；红笔首落 | 已实现（`9121693` 最小钥匙链 + `aa09ce8` 门禁） |
| K2 教具室钥 | S 由侧室变必经（门楔、检修盖、K3 所在） | **巡逻升级**：教师行为库解锁「查柜/先扫藏点」；玩家在 S 的安全感被定价 | 设计已定，**集成待办（教师域行为库）**；本轮红笔落点先行呈现 |
| K3 出口前室钥 | G 由禁区变终局舞台（三档卷栅所在） | **终局对峙**：抬栅噪声预算成为主矛盾；广播异变前置在此备齐（停播+档位），异变台词作高潮引信 | 门禁已实现；异变本轮落地；G 侧巡逻加密为**集成待办（教师域）** |

**验收口径（给审核/ark）**：盲测时问玩家「拿到这把钥匙后，什么变危险了？」——答不出威胁变化的那把钥匙，就是清单不是节拍器，优先返工它而不是加第四把钥匙。明确不做第四钥（沿 gated §4.1）。
